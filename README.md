# 컴퓨터전자공학과 통합 학사 다중 게시판

FastAPI + SQLite3 + Tailwind CSS(CDN)로 만든 단일 파일(`app.py`) 다중 게시판입니다. 바이브 코딩(AI 에이전트와의 대화)으로 개발했습니다.

## 실행 방법

```powershell
pip install -r requirements.txt
python app.py
```

브라우저에서 http://127.0.0.1:8000 접속. 최초 실행 시 `board.db`가 자동 생성되고 시드 데이터(공지 1, 자유 2, Q&A 1)가 들어갑니다.

## 구현 기능
- 게시판 3종: 공지사항(`notice`), 자유게시판(`free`), Q&A게시판(`qna`)
- 텍스트 기반 CRUD (목록, 조회, 작성, 수정, 삭제), 조회수
- 가상 계정 3개와 헤더의 원클릭 전환 (쿠키 기반)
  - `ce_admin` 학과사무실 관리자 (ADMIN)
  - `ce_202601` 김전자 (USER)
  - `ce_202602` 이컴공 (USER)
- 역할 기반 접근 제어 (RBAC)

| 게시판 | 학생(USER) | 관리자(ADMIN) |
|---|---|---|
| 공지사항 | 조회만 가능 (글쓰기 버튼 숨김) | 조회, 작성, 모든 글 수정/삭제 |
| 자유/Q&A | 조회, 작성, 본인 글 수정/삭제 | 조회, 작성, 타인 글도 수정/삭제 |

- 비인가 접근(예: 학생의 `/write?board=notice` 직접 진입, 타인 글 수정/삭제 요청)은 백엔드에서 HTTP 403으로 차단하고 경고 화면을 출력합니다.
